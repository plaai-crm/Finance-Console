ทดสอบผ่านเบราว์เซอร์ในโหมดข้อมูลจำลองแล้ว:

- รายจ่ายกำหนดเดือนก่อน แต่จ่ายเงินจริงเดือนปัจจุบัน 1,000 บาท แสดงใน “จ่ายเงินจริงเดือนนี้” และกระแสเงินสดเดือนปัจจุบันถูกต้อง
- บัญชี Owner เห็นเมนู Wealth; บัญชี Staff ขอบเขตทั่วไปไม่เห็นเมนูปล่อยกู้/ลงทุน/เอกสาร Wealth
- ฟอร์มรายจ่ายที่เลือก “จ่ายแล้ว” แสดงและบันทึกช่อง “วันที่จ่ายเงินจริง”

จุดที่ยังต้องทดสอบกับ staging/ระบบจริงก่อนเปิดใช้ คือ Edge Function login, RLS ของบัญชีจริง, private Storage signed URL, recurring RPC และ LINE delivery เพราะต้องอาศัย schema/config/secret ของโปรเจกต์ Supabase จริง
